# cryptum

Консольная программа для шифрования текста и файлов.
РГР по дисциплине «Программирование», НГТУ, гр. АБс-527, Шнитко Н. С.

Алгоритмы подключаются как динамические библиотеки:
- Атбаш
- двойная табличная перестановка
- TEA (режим CBC)

## Сборка

Linux:
```
make
make test
```

Windows (MinGW-w64):
```
build.bat
```

## Запуск

```
./bin/cryptum       # меню
./bin/cryptum -h    # справка
```

## Установка

- Linux: `sudo ./install.sh`, удаление `sudo ./uninstall.sh`
- Windows: `install.bat` и `uninstall.bat` от имени администратора

## Структура

- `src/` — главный модуль: меню, работа с файлами, загрузка библиотек
- `ciphers/` — библиотеки алгоритмов
- `include/` — общий интерфейс библиотек
- `tests/` — автоматические тесты
- `files/` — рабочие папки: input, keys, output
